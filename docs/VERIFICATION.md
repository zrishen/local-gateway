# 验证说明

本文件只保留可公开复述的验证范围；具体入口 IP、公司域名、内网地址和本机日志不在公开仓库中保留。

## 已验证能力

| 领域 | 验证 |
|---|---|
| 单端口代理 | HTTP、HTTPS CONNECT、SOCKS5 和本地 AI 入口 |
| TUN 路径 | 公网域名、规则分流、DNS 和静态资源下载 |
| 系统代理 | 项目常开、SakuraCat 覆盖、关闭后自动恢复 |
| 节点选线 | 地区内测速、当前节点健康检查、失效后重新选择 |
| 入口 IP | 多候选 TCP/TLS 探测、死地址排除、失效切换 |
| 入口历史 | 成功保留、失败淘汰、短期墓碑、每域名上限 |
| 公司内网 | 可选域名和内部 DNS 配置；未配置时自动省略相关规则 |
| Codex 路由 | 模型目录、思考档位、官方与第三方认证隔离 |
| 回归测试 | 本地单元测试覆盖配置、选线、入口、网关和协议转换 |

## 重要行为

- 节点出站绑定物理网卡，避免代理连接再次进入自己的 TUN。
- DNS 返回的入口地址不会直接信任，必须通过 TCP + TLS 检查。
- 运行时每个节点最多选择 3 个健康入口，历史记录只用于候选和恢复。
- 入口记录会自动清理，不会因为 DNS 持续返回死地址而无限增长。
- 系统代理通过真实 Windows 注册表切换进行过对照测试。
- 健康检查中的 HTTP 403/404 仅表示 TLS/HTTP 可达，不代表业务登录成功。

## 限制

- 真实网络质量受服务商线路、跨境拥塞和本地运营商影响；
- 入口 IP 会变化，不能保证某个地址长期有效；
- 短时间测速不能代表持续带宽；
- 公司 DNS、AI 上游和第三方模型需要使用者自行配置；
- 本项目不绕过证书验证，也不保证任何第三方订阅或 API 的可用性。
